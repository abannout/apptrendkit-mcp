# Changelog

The hosted server at `https://www.apptrendkit.com/mcp` always runs the latest version. Tool names and existing inputs are never renamed or removed; new inputs are optional.

## 1.0.0 (2026-10-24)

First public release.

- Five read-only tools: `search_apps`, `get_app_details`, `get_top_charts`, `check_keyword_difficulty`, `calculate_app_store_proceeds`.
- Inline results view for ChatGPT and Claude (MCP Apps), `ui://apptrendkit/results-v2.html`.
- Streamable HTTP, no authentication.
